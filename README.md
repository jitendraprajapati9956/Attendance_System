# Student Attendance Management System

This is a simple web-based **Student Attendance Management System** built with **PHP** and **MySQL**. It allows users to manage student attendance, view subjects, and perform user-related actions like login, registration, and profile editing.

## 💡 Features

- Admin login/logout
- Add new subjects
- Record student attendance
- View attendance by subject
- Edit user profile
- Forgot password feature

## 🗂️ Project Structure

| File | Description |
|------|-------------|
| `addattendance.php` | Add new attendance records |
| `addsub.php` | Add a new subject |
| `attendance.php` | View/manage attendance |
| `attendance.sql` | Database schema file |
| `dashboard.php` | Admin/user dashboard |
| `db.php` | Database connection configuration |
| `editprofile.php` | Edit user profile |
| `forgot.php` | Forgot password functionality |
| `login.php` | User login page |
| `logout.php` | User logout script |
| `new.php` | Likely handles new user or student addition |
| `subject.php` | Subject management |
| `viewattend.php` | View attendance records |
| `viewsub.php` | View subjects |
